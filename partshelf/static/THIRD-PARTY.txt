To rebuild or replace it, follow occt-import-js tools/build_wasm.py instructions at the source repository, replace dist/occt-import-js.js and .wasm, and run npm run build:viewer followed by npm run package:desktop. Packager does not modify OCCT WASM. desktop/viewer/csp-runtime.mjs replaces the JavaScript embind dynamic invokers with ordinary closures so string evaluation stays disabled.
